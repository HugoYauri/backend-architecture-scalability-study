# Results

## Current status

This folder is currently empty except for placeholder files. No experiments have been run yet, so there are no figures or metrics to show. See docs/05-expected-results.md for what running the demos with a load-testing tool would be expected to produce, and docs/04-limitations.md for why nothing is reported here yet.

## Structure

- figures/: intended for charts or diagrams generated from measured data (for example, request-distribution bar charts). Empty for now.
- metrics/: intended for raw or summarized numeric output (for example, CSV or JSON files with request counts, latencies, or cache hit ratios). Empty for now.

## If you add results here

Please link back to the exact demo and command in src/ that produced them, and to any data/raw/ files they were derived from, so the chain from raw data to result is auditable.
