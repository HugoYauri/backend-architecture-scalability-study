# Data

## Current status

This folder is currently empty except for placeholder files. The source study guide is conceptual and does not include a dataset. See docs/04-limitations.md.

## Structure

- raw/: intended for unprocessed data captured directly from running the demos in src/ (for example, raw request logs or load-test output). Nothing has been collected yet.
- processed/: intended for cleaned or aggregated versions of the raw data (for example, summarized request counts). Nothing has been produced yet.

## If you add data here

Please include, alongside any file you add: the exact command or tool used to generate it, the date it was generated, and the hardware/environment it was generated on. This keeps every number traceable to how it was produced, consistent with this repository's approach to avoiding unverified claims (see docs/04-limitations.md and docs/05-expected-results.md).
