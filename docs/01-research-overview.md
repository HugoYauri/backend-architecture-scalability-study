# Research Overview

## Context

The source material for this repository is a study guide titled "Arquitectura avanzada de backend - Guia por subtemas" ("Advanced backend architecture - a guide by sub-topics"), provided by the repository owner. It states it is based on a video that builds a Google Drive clone, evolving the architecture step by step. The guide is organized into 12 blocks (Block 0 through Block 11) plus a synthesis and a suggested study path, and follows one recurring principle: separation of responsibilities, applied at increasing scale.

## What this repository does

- Translates and reorganizes the original notes into English, one file per block, under docs/study-guide/.
- Extracts explicit research questions from the guide's own study questions and from the logical structure of the material.
- Adds a methodology section clarifying how the guide was processed and how the small reproducible demos in src/ relate to it.
- Documents, without exception, what is missing from the source (primary citation, formal references, empirical data).

## What this repository does not do

- It does not claim to be a peer-reviewed academic study.
- It does not present any number from the original guide (for example, "500 users", "10 requests per minute", "50 MB", "about 20 ms") as a measured result. These are illustrative examples from the source material.
- It does not fabricate a bibliography for concepts that, in the original material, are not attributed to any specific paper or book.
