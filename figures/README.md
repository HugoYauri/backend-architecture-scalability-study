# Figures

This folder holds architecture diagrams for the study guide.

For reproducibility and easy diffing in version control, diagrams are kept as text-based Mermaid definitions inside Markdown files (see architecture-evolution-overview.md) rather than as binary images. Mermaid diagrams render automatically in the GitHub web UI.

No rendered raster/vector image exports (PNG/SVG) have been generated yet; see docs/06-future-work.md.
